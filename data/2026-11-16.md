Abstract: Strong gravitational lens modelling requires the lens light, lensed source light, and contaminants to be separated in each image before mass modelling codes can fit the system. Within Euclid this separation has so far been done by hand, which does not scale to the more than 15,000 candidates in the Euclid Lens Identification Pipeline and Scientific Exploration (ECLIPSE) catalogue of Data Release 1 (DR1). We present AstroVink-TREX , a neural network that performs this separation automatically and predicts three flux maps, in a standard format directly usable by mass-modelling pipelines. The network uses a hybrid architecture, pairing a vision transformer encoder reused from the lens detection network with a parallel convolutional branch. A custom loss function penalises both flux and structural error, while allowing independent weighting per component. From the network's predictions we also derive the modelling centre, fitting region, conjugate points, and binary maps, providing all the inputs that a modelling pipeline needs to run without manual setup. We evaluate the efficiency of the network on DR1 systems against existing fits and through expert validation. Across approximately 3000 inspected systems, taking 75% agreement between inspectors, just 39 lens models fail because of a segmentation error. Following this validation, the network provides the component separation and modelling setup for every system modelled in DR1. With automated segmentation, lens modelling is no longer limited by manual preprocessing and can now operate at the same scale as lens discovery.

Motivation: FRB（部分为重复暴）的辐射机制与引擎活跃寿命尚不清楚。直接观测难以跨越数年乃至更长的源内时间跨度，而星系团强透镜自带已知相对时延，可在短观测期内采样相隔多年的源帧发射历元，从而绕开长基线监测的限制。

Method: 基于MACS J0717.5+3745的星系团透镜模型，量化在有限活动时段、有限观测窗口与发现选择效应下可及的发射历元范围。核心逻辑：不同透镜像中出现彼此不同的暴，在已知相对时延下可给出活跃寿命下界；而同一暴的延时复制只编码透镜时延本身。进一步在群体层面把"不同暴的跨像关联"与"同一暴的回波"结合，用有限透镜样本对指定活动时长做贝叶斯模型检验。

Result: 以 z_s=2、源帧活动时长100 yr、源帧暴率0.1 h_src^-1 为例，条件于被发现情形下，五年观测给出95%增益阈值 m_95≈25.6，对应源帧可及跨度 L_95≈42.6 yr。群体层面，结合跨像暴关联与同暴回波，可在有限透镜编目下检验指定活动时长；活动时长相差一个量级时，预期贝叶斯因子可高于20。

Conclusion: 星系团透镜是观测FRB源未被直接看到的"历史"、区分不同活动时长模型的有前景途径；透镜化的源帧历元还可用于把暴的活动与引擎及其环境的演化联系起来。
